# 🚀 Sanika Pawar's Portfolio

## 🌟 Overview

A modern, responsive portfolio website showcasing my skills, projects, education, certifications, and professional journey. Built with a clean dark theme, premium gradients, smooth animations, and a polished user experience.

## ✨ Features

- 🎨 **Modern Design**: Dark luxury portfolio theme with glassmorphism and gradient accents
- 📱 **Fully Responsive**: Optimized for desktops, tablets, and mobile devices
- ⚡ **Smooth Animations**: Scroll reveal effects and elegant hover transitions
- 🌈 **Professional Layout**: Hero section with profile image and left-aligned content
- 🧠 **Strong Personal Branding**: Skills, projects, education, and certifications presented clearly
- 📬 **Contact Ready**: Email, phone, location, and LinkedIn access in one place

## 🚀 Getting Started

1. Clone or download this project to your local machine.
2. Open the project folder.
3. Open `index.html` directly in a browser, or run a local server:

```bash
cd Portfolio-main
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
